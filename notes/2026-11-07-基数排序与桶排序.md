## ① 基本概念与术语表

| 术语 | 含义 |
| --- | --- |
| 稳定排序 | 相等元素排序后相对顺序不变。基数排序每轮**必须**用稳定排序 |
| 计数排序 | 值域 0..k，统计出现次数 + 前缀和后直接落位；O(n+k)，稳定 |
| 基数排序（Radix Sort） | 不比较元素大小，按"位"逐轮分桶排序。分 LSD（低位优先）与 MSD（高位优先） |
| LSD（Least Significant Digit） | 从最低位到最高位逐轮做稳定排序；实现简单，最常用 |
| MSD（Most Significant Digit） | 从最高位开始分桶，桶内递归排下一位；适合变长字符串 |
| 桶排序（Bucket Sort） | 把数据均匀映射到若干桶，桶内各自排序后拼接；依赖输入均匀分布 |
| 位/关键字 | 一个数按 10 进制（或字符串按字符）拆出的单个分量 |
| 桶宽（bucket width） | 每个桶覆盖的值域区间长度 |

## ② 核心性质（带说明）

1. **LSD 正确性依赖"稳定"**：每一轮按第 d 位排序时，前面几轮排出的相对顺序必须保留。
   归纳证明：排完第 d 位后，任取两数 x、y（x 在 y 前）。若第 d 位不同，则 x 的第 d 位更小，
   它们顺序已正确；若第 d 位相同，稳定性保证它们保持"更高位已排好序"的相对顺序。
   → **每轮排序必须稳定，否则前功尽弃**（这是与普通排序最大的区别）。
2. **LSD 复杂度**：n 个数、最大值有 d 位、每位值域 k=10：
   每轮 O(n+k)，共 d 轮，总计 **O(d·(n+k))**。d 通常很小（如 32 位整数 d≤10），
   可视为线性排序，**突破了比较排序 O(n log n) 下界**（因为它不是比较排序）。
3. **MSD 对变长字符串**：按字符分桶，"已到末尾的短串"单独放 0 号桶不再递归
   （短串字典序小于任何以它为前缀的长串）。复杂度 O(N·L) 量级，L 为平均长度。
4. **桶排序期望 O(n)**：n 个 [0,1) 均匀随机数，桶号 = ⌊v·n⌋，每桶期望 1 个元素；
   桶内插入排序期望代价为 O(1)，总期望 **O(n)**。
   但**最坏退化为 O(n²)**——所有元素落进同一个桶时，就是一次纯插入排序。
5. **三者的关系**：计数排序是"值为关键字、一个值一个桶"的桶排序；
   基数排序是"多轮计数排序"的组合；桶排序是它们的泛化思想——**用空间和分布换比较**。

## ③ 存储结构（顺序 vs 链式）

这三种排序都不需要"结构"，核心辅助结构是**桶**：

| 实现 | 写法 | 优缺点 |
| --- | --- | --- |
| 顺序（vector 嵌套） | `vector<vector<int>> bucket(k)` | 简单直观，桶内顺序即入桶顺序，天然稳定；推荐 |
| 链式（拉链） | 每桶一条单链表，尾插 | 省内存拷贝，但 C++ 手写繁琐，教学场景没必要 |
| 计数数组 | `int cnt[k]`，前缀和回填 | 不存数据本身，只存"位置"，是 LSD 每轮的标准实现 |

```cpp
// LSD 每轮的"桶"其实就是 10 个计数器（0~9 十种位值）
void countingSortByDigit(vector<int> &a, int d) {
    int n = (int)a.size();
    vector<int> out(n);
    int cnt[10] = {0};
    for (int x : a) cnt[digitOf(x, d)]++;        // 计数
    for (int v = 1; v < 10; v++) cnt[v] += cnt[v-1]; // 前缀和 = 排名
    for (int i = n-1; i >= 0; i--) {             // 从后往前 → 稳定
        int dig = digitOf(a[i], d);
        out[cnt[dig] - 1] = a[i];
        cnt[dig]--;
    }
    a = out;
}
```

```cpp
// 桶排序：顺序实现的桶数组，映射 桶号 = (int)(v * n)
vector<vector<double>> buckets(n);
for (double v : a) buckets[(int)(v * n)].push_back(v);
for (auto &b : buckets) insertionSort(b);        // 桶内插入排序
```

## ④ 核心操作实现思路

**LSD 基数排序**（整数）：
1. 求最大值的位数 d，决定排序轮数；
2. 从个位到最高位，每轮对当前位做一次**稳定计数排序**；
3. 全部轮次结束后即为有序。

**双关键字排序（扑克牌：主关键字=花色，次关键字=点数）**：
按 LSD 原则——**先按次关键字（点数）稳定排一遍，再按主关键字（花色）稳定排一遍**。
第二轮稳定排序自动保留了同花色内按点数的顺序。

**支持负数的基数排序**：
负数、非负数分组 → 负数取绝对值 LSD 排好后**反转**再恢复负号 → 两组拼接。

**MSD 基数排序**（字符串）：
区间 [lo,hi] 按第 pos 个字符分 257 个桶（0 号放"到末尾的短串"）→ 依次写回 →
对每个非 0 号桶递归 pos+1。

**桶排序**：
确定映射函数（均匀分布用 ⌊v·n⌋）→ 分桶 → 桶内插入排序 → 按桶序拼接。

**最大间距问题（桶思想，LeetCode 164）**：
n 个数均分成 n-1 个桶（含 min、max 各自所在桶），由抽屉原理**最大间距必出现在
相邻两个非空桶之间**（后桶最小值 − 前桶最大值），同桶内间距必小于桶宽，无需比较。
只需记录每桶的 min/max，一趟 O(n)。

## ⑤ 复杂度小结

| 算法 | 时间（平均） | 时间（最坏） | 空间 | 稳定 | 适用场景 |
| --- | --- | --- | --- | --- | --- |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | ✔（从后往前回填） | 值域小且为整数 |
| LSD 基数排序 | O(d(n+k)) | O(d(n+k)) | O(n+k) | ✔ | 定长关键字：整数、定长串 |
| MSD 基数排序 | ~O(N·L) | ~O(N·L) | O(桶总数) | ✔ | 变长字符串 |
| 桶排序 | O(n)（均匀分布） | **O(n²)** | O(n) | ✔（桶内排序稳定时） | 均匀分布的浮点数 |
| （对照）快排 | O(n log n) | O(n²) | O(log n) | ✘ | 通用 |

## ⑥ 常见易错点

1. **基数排序每轮必须稳定**：用"从后往前回填"的计数排序实现稳定性；
   若从前往后回填，相等位的元素相对顺序被颠倒，结果错误。
2. **前缀和的含义**：`cnt[v] = ≤v 的元素个数`，落位下标是 `cnt[v] - 1` 而不是 `cnt[v]`。
3. **LSD 从低位开始**，MSD 从高位开始，两者方向弄反会得到完全错误（甚至不是任何已知）的结果。
4. **位数统计**：0 的位数是 1（`while (x > 0)` 循环要初始化 t=1 或用 do-while 处理 x=0），
   否则 0 会被当作 0 位。
5. **双关键字顺序**：先排**次**关键字，再排**主**关键字（很多教材考这个顺序，容易背反）。
6. **桶排序的映射**：⌊v·n⌋ 要求 v ∈ [0,1)；若 v=1 会越界（需 min(v, 0.999) 或开 n+1 个桶）。
7. **桶排序最坏 O(n²)** 来自"全落一个桶 + 插入排序"，并非桶排序理论保证线性；
   面试说"桶排序 O(n)"必须带上"输入均匀分布"的前提。
8. **最大间距的桶宽**要**向上取整**：`width = ceil((mx-mn)/(n-1))`，用整数运算写成
   `(mx - mn + n - 2) / (n - 1)`，向下取整会导致答案跨桶判断失效。
9. **负数不能直接取位**：LSD 的"位"只对非负整数有意义，负数先分组或统一加偏移。
10. **稳定性与桶内排序的选择**：想要整体稳定，桶内也要用稳定排序（插入排序 ✔，快排 ✘）。
