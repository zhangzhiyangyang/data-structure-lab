# 树与二叉树

> 学习笔记 · 2026-10-15 · 配套代码：[`code/2026-10-15-binary_tree.cpp`](../code/2026-10-15-binary_tree.cpp)

## 一、树的基本概念

**树**是 n（n ≥ 0）个结点的有限集合。当 n = 0 时称为空树；当 n > 0 时，有且仅有一个根结点，其余结点可分为 m（m ≥ 0）个互不相交的子集，每个子集本身又是一棵树，称为根的**子树**。

常用术语：

| 术语 | 含义 |
| --- | --- |
| 结点的度 | 该结点拥有的子树个数 |
| 树的度 | 树中所有结点度的最大值 |
| 叶子结点 | 度为 0 的结点 |
| 分支结点 | 度不为 0 的结点 |
| 孩子 / 双亲 | 某结点的子树的根称为它的孩子，该结点称为孩子的双亲 |
| 兄弟 | 同一个双亲的结点互称兄弟 |
| 层次 | 根为第 1 层，其孩子为第 2 层，依次类推 |
| 树的深度 | 树中结点的最大层次 |
| 森林 | m（m ≥ 0）棵互不相交的树的集合 |

## 二、二叉树

**二叉树**是 n（n ≥ 0）个结点的有限集合，它或者是空树，或者由一个根结点加上两棵分别称为**左子树**和**右子树**的、互不相交的二叉树组成。

注意：二叉树**不是**度为 2 的有序树。二叉树的子树有严格的左右之分，即使只有一棵子树也要区分是左还是右。

### 几个重要性质

1. 第 i 层上至多有 `2^(i-1)` 个结点（i ≥ 1）。
2. 深度为 k 的二叉树至多有 `2^k - 1` 个结点（k ≥ 1）。
3. 对任意二叉树，若叶子结点数为 `n0`、度为 2 的结点数为 `n2`，则 `n0 = n2 + 1`。
4. 具有 n 个结点的**完全二叉树**深度为 `⌊log₂n⌋ + 1`。

### 两种特殊形态

- **满二叉树**：深度为 k 且含有 `2^k - 1` 个结点的二叉树，每一层都排满。
- **完全二叉树**：只有最下面两层结点的度小于 2，且最下层结点集中在左侧连续排列。

完全二叉树适合用**顺序存储**（数组下标从 1 开始，结点 i 的左孩子为 2i、右孩子为 2i+1、双亲为 ⌊i/2⌋），普通二叉树则用**链式存储**更合适：

```cpp
typedef struct BiTNode {
    ElemType data;                    // 数据域
    struct BiTNode *lchild, *rchild;  // 左右孩子指针
} BiTNode, *BiTree;
```

## 三、二叉树的遍历

遍历是按某条搜索路径依次访问树中每个结点，且每个结点仅访问一次。

| 遍历方式 | 访问顺序 |
| --- | --- |
| 先序（DLR） | 根 → 左子树 → 右子树 |
| 中序（LDR） | 左子树 → 根 → 右子树 |
| 后序（LRD） | 左子树 → 右子树 → 根 |
| 层次 | 从上到下、从左到右逐层访问 |

先序、中序、后序的**递归**写法只是访问语句的位置不同，结构完全一致：

```cpp
void InOrder(BiTree T) {
    if (T) {
        InOrder(T->lchild);
        visit(T);            // 这一行换个位置就变成先序 / 后序
        InOrder(T->rchild);
    }
}
```

递归遍历的时间复杂度 O(n)，空间复杂度 O(h)，h 为树高（递归栈深度）。

**非递归**实现需要显式用栈模拟递归：

- 中序：一路向左入栈，无法向左时出栈访问，再转向右子树。
- 先序：访问结点后先压右孩子、再压左孩子，保证左孩子先出栈。
- 后序：最直接的做法是「先序的镜像（根-右-左）」再整体逆序，利用双栈实现。
- 层次：用**队列**实现，出队访问该结点，并把它的左右孩子依次入队。

## 四、由遍历序列确定二叉树

- **中序序列 + 先序序列**可以唯一确定一棵二叉树；
- **中序序列 + 后序序列**也可以唯一确定一棵二叉树；
- **先序 + 后序**不能唯一确定，因为无法判断只有一个孩子时它是左还是右。

手工还原的套路：先序的第一个（或后序的最后一个）一定是根，拿着这个根去中序序列里切分出左右子树，再对左右子树递归做同样的事。

## 五、常见易错点

1. 空树判断写成 `if (T)` 而不是 `if (!T)`，导致一进函数就返回 —— 递归终止条件要写清楚。
2. 混淆「二叉树的度」和「树的度」：二叉树每个结点度数 ≤ 2，与树的度定义不同。
3. 层次遍历忘了先判空、或把 `push` 和 `pop` 的顺序写反。
4. 非递归后序遍历直接照抄中序的框架，导致根结点被访问两次。
5. 用顺序存储表示非完全二叉树时按 2i / 2i+1 计算下标，会浪费大量空间甚至越界。

## 七、复杂度小结

| 操作 | 时间复杂度 | 空间复杂度 |
| --- | --- | --- |
| 递归遍历（前/中/后序） | O(n) | O(h) |
| 非递归遍历 | O(n) | O(h) |
| 层次遍历 | O(n) | O(w)，w 为最大层宽 |
| 求结点数 / 深度 / 叶子数 | O(n) | O(h) |
