## ① 基本概念与术语表

| 术语 | 含义 |
| --- | --- |
| 顶点 / 弧 / 边 | 图的基本单元；有向图中称「弧 <u, v>」，无向图中称「边 (u, v)」 |
| 有向图 / 无向图 | 边是否有方向。无向图中 (u,v) 等价于 (v,u) |
| 度 / 入度 / 出度 | 与顶点关联的边数；有向图分为入度（射入）与出度（射出），且 总度 = 总入度 = 总出度 = 边数 |
| 权 / 网 | 边上带数值的图称为「网」（网络） |
| 路径 / 路径长度 | 顶点序列 v1→v2→…→vk；长度 = 边数（无权）或边权之和（带权） |
| 连通 / 连通图 | 无向图中 u 到 v 有路径则连通；任意两顶点连通的图为连通图 |
| 强连通图 | 有向图中任意两顶点互相可达 |
| 生成树 | 连通图含全部 n 个顶点的极小连通子图，恰有 n−1 条边 |
| 最小生成树（MST） | 带权连通图中边权之和最小的生成树 |
| 环 / 回路 | 起点终点相同的路径；树 = 无环连通图 |
| 完全图 | 无向完全图有 n(n−1)/2 条边，有向完全图有 n(n−1) 条弧 |

## ② 核心性质与定理

1. **握手定理**：无向图所有顶点度数之和 = 2×边数。推论：度数为奇数的顶点个数必为偶数。
2. **边数上下界**：n 个顶点的无向简单图，边数 e 满足 0 ≤ e ≤ n(n−1)/2；e < n−1 必不连通，e > n−1 必有环。
3. **生成树恰有 n−1 条边**：连通图中删去环上任意一条边仍连通；反之，n−1 条边 + 连通 ⟺ 是一棵树。这是「判断无向图是否为树」的依据（边数 = n−1 且连通）。
4. **MST 的安全边定理（切割性质）**：把顶点集切成两个不相交子集，横跨切口的权最小的边一定属于某棵 MST。Prim 每次挑「树内 → 树外」最小边、Kruskal 按权升序挑不成环的边，本质上都在利用该性质。
5. **MST 唯一性**：各边权互不相同时 MST 唯一；有相同权值时 MST 可能不唯一，但**总权值唯一**。
6. **Dijkstra 贪心正确性的前提**：所有边权**非负**。因为「已确定的最短距离不会再被更新」依赖 dist 非降；有负权边时必须改用 Bellman-Ford / SPFA。
7. **DFS 与 BFS 的时间复杂度相同**（O(n+e)），差别在于访问顺序：DFS 一条路走到黑（栈/递归），BFS 逐层扩散（队列）。无权图中 BFS 首次到达某点的路径即最短路径——这是 BFS 求单源最短路、统计最短路径条数的原理。

## ③ 存储结构：邻接矩阵 vs 邻接表

| 维度 | 邻接矩阵（顺序） | 邻接表（链式/动态数组） |
| --- | --- | --- |
| 空间 | O(n²)，与边数无关 | O(n + e) |
| 判断 (u,v) 是否存在 | O(1) | O(deg(u)) |
| 遍历全部邻居 | O(n) | O(deg(u)) |
| 适合场景 | 稠密图、需频繁查询任意边 | 稀疏图、频繁遍历邻居 |
| 缺点 | 稀疏图浪费大量空间 | 无向图每条边存两份；不易判断两点是否相邻 |

```cpp
// 邻接矩阵：n×n 方阵，g[u][v] = 边权；无边用 INF 哨兵表示
const int INF = 0x3f3f3f3f;
struct MGraph {
    int n;
    vector<vector<int>> g;              // g[u][v] = w，无边为 INF
    explicit MGraph(int n) : n(n), g(n, vector<int>(n, INF)) {
        for (int i = 0; i < n; ++i) g[i][i] = 0;   // 自己到自己为 0
    }
    void addEdge(int u, int v, int w) { g[u][v] = w; g[v][u] = w; } // 无向图对称
};

// 邻接表：每个顶点挂一个邻居链（这里用 vector 模拟）
struct Edge { int to; int w; };
struct ALGraph {
    int n;
    vector<vector<Edge>> adj;           // adj[u] = u 的所有出边
    explicit ALGraph(int n) : n(n), adj(n) {}
    void addEdge(int u, int v, int w) {          // 无向边存两份
        adj[u].push_back({v, w});
        adj[v].push_back({u, w});
    }
    void addDirectedEdge(int u, int v) { adj[u].push_back({v, 1}); } // 有向边存一份
};
```

> 注：教材用「顶点表 + 边链表」的静态链式写法（`VNode firstarc` + `ArcNode next`），思路相同；工程上用 `vector<vector<Edge>>` 更简洁安全。

## ④ 核心操作的实现思路

- **DFS（深度优先）**：从起点出发，访问一个未访问邻居并递归深入，走不通再回溯。用 `vis[]` 数组防止绕环死循环。递归深度可能达 O(n)，图很大时可改为显式栈。
- **BFS（广度优先）**：队列 + 标记数组。出队一个点时把所有未访问邻居**先标记再入队**（入队时标记，否则同一层会重复入队）。BFS 层序 = 无权最短距离。
- **Prim（加点法，稠密图友好）**：维护 `low[v]` = 树外点 v 到当前树的最小边权。每轮 O(n) 挑最小的树外点加入树，再用新点的出边松弛 `low`。总 O(n²)，适合邻接矩阵存储的稠密图。
- **Kruskal（加边法，稀疏图友好）**：边按权升序排序，依次取最小边，用**并查集**判断两端点是否已连通，不连通则选入。总 O(e log e)，瓶颈在排序。
- **Dijkstra O(n²) 版**：维护 `dist[]`，每轮选未确定点中 dist 最小的加入已确定集，再松弛其出边。适合稠密图 / 邻接矩阵。
- **Dijkstra 堆优化版**：小根堆懒删除（弹出时若记录距离 > 当前 dist 则跳过），总 O((n + e) log n)，适合稀疏图。

## ⑤ 复杂度小结

| 操作 / 算法 | 邻接矩阵 | 邻接表 | 备注 |
| --- | --- | --- | --- |
| DFS / BFS | O(n²) | O(n + e) | 遍历所有点和边 |
| Prim | O(n²) | — | 挑最小 low 需扫全表 |
| Kruskal | — | O(e log e) | 瓶颈是排序，另需并查集近 O(e α(n)) |
| Dijkstra | O(n²) | O((n+e) log n)（堆优化） | 要求边权非负 |
| BFS 无权最短路 | O(n²) | O(n + e) | 天然求出最短路径条数 |

## ⑥ 常见易错点

1. **BFS 忘记「入队时标记」**：若改为出队时才标记，同一顶点会重复入队，复杂度退化甚至爆内存。
2. **无向图的边存两份**：邻接表存边数时注意实际边数 = 邻接表总长度 / 2；DFS/BFS 都要对 `vis` 判重。
3. **DFS 忘记初始化/清空 `vis`**：多次调用（如统计连通分量）时每次都要新数组。
4. **Prim 松弛漏掉 `!in[v]` 条件**：把已入树的点又更新一遍，破坏 low 数组语义。
5. **Kruskal 判断成环**：必须用并查集（或 DFS 判连通），不能只看边数；`unite` 返回 false 要跳过。
6. **并查集不路径压缩 / 不按秩合并**：最坏退化为链，find 变 O(n)。路径压缩一行 `f[x] = find(f[x])` 即可。
7. **Dijkstra 遇到负权边**：结果错误且不易察觉。看到负权立即换 Bellman-Ford/SPFA，不要硬套 Dijkstra。
8. **INF 哨兵溢出**：`dist[u] + w` 在 dist=INF 时会溢出 int。用 0x3f3f3f3f（约 1e9，两倍相加不溢出）并在加法前判断 `g[u][v] != INF`。
9. **拓扑排序用 DFS 直接输出顺序是错的**：DFS 退出序的反序才是拓扑序；用 DFS 做拓扑须按完成时间逆序，Kahn 算法（入度表 + 队列）更直观且能顺便判环。
10. **图不连通时的 Dijkstra/Prim**：扫描发现最小 dist 为 INF 要及时 break/返回 -1，不能输出错误值。

## ⑦ 练习题（答案见配套代码 `code/2026-10-21-graph.cpp`）

1. **判断一棵树**：给定无向图，判断它是否是一棵树。（提示：边数 = n−1 且从任意点 BFS 能覆盖全部 n 个顶点）
2. **最短路径条数**：给定无权无向图和源点 s，求 s 到每个顶点的最短路径长度与条数。（提示：在 BFS 中维护 cnt，`dist[e]==dist[u]+1` 时累加）
3. **连通分量个数**：给定无向图，求连通分量的个数。（提示：并查集，统计根的个数）
4. **拓扑排序判环**：给定有向图，输出一个拓扑序列；若存在环则报告「无法拓扑排序」。（提示：Kahn 算法，出队数 < n 即有环）
5. **对偶练习**：把教材例图分别用 Prim 和 Kruskal 求最小生成树，比较两法选边顺序的差别，并验证总权值一致。
