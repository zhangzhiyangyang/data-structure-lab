# 排序：插入、交换（冒泡/快排）、堆、归并与计数排序

> 对应课程第 29~32 期：插入排序、交换排序、堆排序、归并排序和计数排序。

## 一、基本概念与术语表

| 术语 | 含义 |
| --- | --- |
| 稳定性 | 相等元素排序后相对次序不变，则称排序是稳定的 |
| 内部排序 | 数据全部在内存中完成的排序 |
| 就地排序（in-place） | 只用 O(1) 辅助空间的排序 |
| 比较排序 | 仅通过元素间比较决定次序的排序，下界为 O(n log n) |
| 非比较排序 | 计数/基数/桶排序，可突破比较下界达到 O(n+k) |
| 逆序对 | 序列中 i<j 且 a[i]>a[j] 的数对；插入排序时间与逆序对数成正比 |

## 二、核心性质与推导

1. **插入排序**：第 i 趟把 a[i] 插入已有序的前缀。比较/移动次数 = 初始逆序对数 + O(n)，故最好 O(n)（基本有序），最坏 O(n²)（逆序）。**稳定、就地**。逆序对最多 n(n-1)/2，这给出 O(n²) 的精确界。
2. **冒泡排序**：每趟从后往前把最小元素"冒"到前端（或从前往后把最大元素沉底）；某趟无交换即提前终止，最好 O(n)。**稳定**。交换次数恰等于逆序对数。
3. **快速排序**：每趟选定 pivot（如取区间最右元素），划分后 pivot 就位于最终位置。平均 O(n log n)：递推 T(n)=n+T(k)+T(n-1-k)，随机数据下期望 2n ln n ≈ 1.39 n log₂n。最坏 O(n²)（每次划分极度偏斜，如已有序+取端点）。**不稳定**。空间为递归栈 O(log n)~O(n)。
4. **堆排序**：先自底向上建大顶堆 O(n)，然后每趟把堆顶与末尾交换、堆大小减一、向下调整 O(log n)，共 n-1 趟，总计 O(n log n) 且与初始数据无关。**不稳定、就地**。
5. **归并排序**：分治——递归排左右两半再线性合并。T(n)=2T(n/2)+O(n)=O(n log n)，任何输入都是这个界。**稳定**，但需要 O(n) 辅助数组。
6. **计数排序**：设值域 [0,k]，统计每个值出现次数 c[v]，前缀和 c 得到每个值在结果中的结束位置，**倒序**扫描原数组（保证稳定性）放入 `pos[a[i]]-1`。O(n+k)。非比较排序，可突破 O(n log n) 下界。

## 三、存储结构

排序都作用于顺序表（数组）——需要随机访问下标，链表只适合归并/插入：

```cpp
// 顺序存储：待排记录直接用数组（0 号位存数据而非哨兵，下标从 0 开始）
struct SqList {
    int a[MAXN];   // 静态数组版；实际代码用 vector<int>
    int n;         // 当前长度
};
```

```cpp
// 归并排序需要的辅助数组（与原数组等长）
vector<int> tmp;   // merge 时借用
```

对比：数组支持 O(1) 随机访问，快排划分、堆的下标计算（父 i、孩子 2i+1/2i+2）都依赖它；链表上只有归并排序是自然高效（合并 O(1) 拼接），快排/堆排在链表上退化。

## 四、核心操作实现思路

- **插入**：`tmp=a[i]`，从 j=i-1 起凡 `a[j]>tmp` 就 `a[j+1]=a[j]` 后移，最后放入 `a[j+1]=tmp`。用 `>` 而非 `>=` 保证稳定。
- **冒泡**：双重循环，内层相邻比较 `a[j]>a[j+1]` 则交换；用 `swapped` 标志提前退出。
- **快排**：`partition` 取 `a[hi]` 为 pivot，`i` 指向"小于区"边界，扫描 `lo..hi-1`，凡 `a[j]<pivot` 就与 `a[i++]` 交换；最后把 pivot 换到 `i`。再对左右子区间递归。
- **堆排**：`siftDown(i, size)` 选 i 与两孩子中的最大者，若最大者是孩子则交换并继续下潜；建堆从 `n/2-1` 倒序调用；排序阶段每轮 `swap(a[0], a[size-1])` 再 `siftDown(0, --size)`。
- **归并**：`merge(lo, mid, hi)` 把两个有序段复制进辅助数组后按序写回；递归到长度 ≤1 停止。
- **计数**：找最大值 k → 计数 → 前缀和 → 倒序回填。

## 五、复杂度小结

| 算法 | 最好 | 平均 | 最坏 | 空间 | 稳定 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
| 直接插入 | O(n) | O(n²) | O(n²) | O(1) | ✔ | 基本有序时最快 |
| 冒泡 | O(n) | O(n²) | O(n²) | O(1) | ✔ | 可提前终止 |
| 快速排序 | O(n log n) | O(n log n) | O(n²) | O(log n) | ✘ | 已有序+取端点 pivot 是最坏 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ✘ | 建堆 O(n) |
| 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | ✔ | 链表排序首选 |
| 计数排序 | O(n+k) | O(n+k) | O(n+k) | O(n+k) | ✔ | k 为值域大小 |

## 六、常见易错点

1. 插入排序把比较写成 `a[j]>=tmp` 会破坏稳定性（相等元素被翻越）。
2. 快排划分中扫描用 `a[j]<pivot`（不是 `<=`）：否则相等元素全进左区，划分失衡。
3. 快排对已有序数组取端点 pivot 会退化到 O(n²)；工程上用三数取中或随机 pivot。
4. 堆排建堆必须**从最后一个非叶子结点 `n/2-1` 倒序** siftDown；正序调用会得到错误结构。
5. 堆排是**大顶堆升序**：小顶堆 + 交换堆顶也能做但方向绕晕自己；下标公式（0 起点）父 `i`、孩子 `2i+1/2i+2`，与 1 起点版（2i/2i+1）不同。
6. 归并的合并必须把剩余段一次性拷回，且递归出口是 `lo>=hi`；用 `mid=(lo+hi)/2` 时 `hi` 用闭区间，注意边界一致。
7. 计数排序必须**倒序**回填才是稳定版；正序回填得到的是不稳定的正确结果，但作为基数排序子过程时出错。
8. 冒泡提前终止的标志要在每趟开始时重置。
9. 快排递归区间是 `[lo, p-1]` 与 `[p+1, hi]`，pivot 本身不再参与递归，写成包含 pivot 会死循环。

## 七、练习题

1. 实现直接插入排序并统计比较次数与移动次数；对 `5,2,4,6,1,3` 和完全逆序的 8 个元素分别给出两个计数，验证"移动次数 = 逆序对数 + n-1"。
2. 手工模拟对 `4,5,2,1,3` 的冒泡排序，写出每趟结束后的序列和提前终止发生的那一趟。
3. 对 `6,1,2,7,9,3,4,5,10,8` 执行一次以末元素为 pivot 的 partition，写出返回的下标和划分后的数组。
4. 把 `23,78,45,8,32,56` 依次插入空堆再逐个取堆顶，写出建堆后的数组形态和前三趟堆排序后的数组。
5. 对 `38,27,43,3,9,82,10` 画出归并排序递归树（自顶向下），并写出每一层合并完成后的数组状态。
6. 用稳定版计数排序对 `4,2,2,8,3,3,1` 排序，写出计数数组、前缀和数组与最终结果。
