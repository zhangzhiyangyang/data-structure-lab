# Huffman 树与 Huffman 编码、树与森林转换（课程第 18~19 期）

> 对应代码：`code/2026-10-29-huffman_forest.cpp`

## ① 基本概念与术语表

| 术语 | 含义 |
| --- | --- |
| 路径长度 | 从树中一个结点到另一个结点之间的分支数目 |
| 树的路径长度 | 从树根到每个结点的路径长度之和 |
| 结点的带权路径长度 | 该结点的权值 × 从根到该结点的路径长度（分支数） |
| 树的带权路径长度 **WPL** | 树中**所有叶子结点**的带权路径长度之和：`WPL = Σ wi·li` |
| **哈夫曼树（最优二叉树）** | 由 n 个带权叶子构成的所有二叉树中，WPL 最小的那棵 |
| 前缀码 | 任一字符的编码都不是另一个字符编码的**前缀**的编码方案 |
| 哈夫曼编码 | 把出现频率高的字符放在离根近的位置（编码短）得到的前缀码，总长最短 |
| 孩子兄弟表示法 | 每个结点存"第一个孩子"和"下一个兄弟"两个指针；树/森林转二叉树的标准手段 |

记忆要点：WPL 只统计**叶子**；哈夫曼树里"权越大的叶子离根越近"。

## ② 核心性质与定理

**性质 1：哈夫曼树没有度为 1 的结点，共 2n−1 个结点。**

n 个叶子的二叉树中，设度为 2 的结点有 m2 个、度为 1 的有 m1 个，由边数关系
`n + m1 + m2 − 1 = m1 + 2·m2`（总分支数 = 总结点数 − 1）得 `m0 = m2 + 1`，即 `m2 = n − 1`。
所以总结点数 = `n + (n−1) = 2n−1`。哈夫曼树的构造过程每次合并两个结点生成一个新结点，
"两两合并"决定了根本不会产生度为 1 的结点——这正是 `2n−1` 这个结论的来源。

**性质 2：哈夫曼树的 WPL 是唯一的，但树形（编码方案）不唯一。**

权值并列时选哪一对先合并都可以，得到的树形状不同、各叶子的编码也不同，
但只要每步都选当前最小的两个，WPL 一定相同且最优。

**性质 3（贪心正确性，交换论证思路）：**
设 T 是 WPL 最小的树，a、b 是权值最小的两个叶子。
- 在最优树中，最小权 a 的深度一定 ≥ 任何其他叶子的深度（否则与更深的叶子交换，WPL 变小，矛盾）；
- 把 a 与最深层某叶子交换、b 与其兄弟交换，WPL 不增——于是可设 a、b 在最深层且为兄弟；
- 把 a、b 合并成权 `wa+wb` 的新叶子，得到 n−1 个叶子的子问题。由归纳假设子问题的最优解
  加回这一次合并就是原问题的最优解。

这也解释了为什么"每次选最小两个合并"的贪心是对的。

**性质 4：哈夫曼编码一定是前缀码。**
字符只对应**叶子**，而从根到一个叶子的路径不可能经过另一个叶子（叶子没有孩子），
所以任何编码都不会是另一个编码的前缀——解码时不会产生歧义。

**性质 5：哈夫曼树不一定是完全二叉树。**
权值悬殊时（如 {1,1,1,8}）树会向大权一侧"偏斜"，深度可远大于 ⌈log2 n⌉。

## ③ 存储结构

| 方案 | 结构 | 优点 | 缺点 |
| --- | --- | --- | --- |
| 顺序（静态三叉链表） | 数组，每个结点存 `weight / parent / lchild / rchild` | 不用指针、"从叶向根回溯"求编码极方便（顺 parent 走）；数组大小固定 2n−1 | 需要预先知道 n；插入删除不灵活 |
| 链式（二叉链） | 指针结点 `weight / lchild / rchild` | 结构通用，可与普通二叉树代码复用 | 求编码只能从根 DFS；没法向上走 |

教材（严蔚敏）经典写法是**顺序存储**，本代码两种思路都体现：树用静态数组建，
编码既演示"叶→根回溯"，也演示"根→叶 DFS"。

```cpp
// ---- 顺序（静态三叉链）存储：下标从 1 开始，共 2n-1 个有效结点 ----
struct HTNode {
    int weight;             // 权值
    int parent;             // 双亲下标，0 表示还没有双亲
    int lchild, rchild;     // 左右孩子下标，0 表示无孩子
};
// HT[1..n]     : n 个叶子（原始权值）
// HT[n+1..2n-1]: n-1 个新合并出来的内部结点，HT[2n-1] 是根

// ---- 链式存储：树/森林转二叉树用的孩子兄弟结点 ----
struct CSNode {
    char    val;            // 结点值
    CSNode* firstChild;     // 第一个孩子（转二叉树后成为左孩子）
    CSNode* nextSibling;    // 下一个兄弟（转二叉树后成为右孩子）
};
```

## ④ 核心操作的实现思路

### 1. 构建哈夫曼树（选两个最小合并，n−1 轮）
1. 开 `2n` 大小的数组（0 号弃用），把 n 个权值放进 `HT[1..n]`，parent/lchild/rchild 全 0；
2. 重复 n−1 次：在**parent==0** 的结点中扫出权最小的两个下标 s1、s2（并列时任取）；
3. 新结点 `HT[i]`：weight = 两权之和，lchild=s1、rchild=s2；把 s1、s2 的 parent 指向 i；
4. 结束时 `HT[2n-1]` 即根。
每轮 O(n) 扫描、共 n−1 轮 → O(n²)；用优先队列（小根堆）可优化到 O(n log n)。

### 2. 求 WPL
- 方式 A（自顶向下 DFS）：从根出发，深度每下一层 +1，到叶子时累加 `weight×depth`；
- 方式 B（自底向上）：对每个叶子沿 parent 链走到根数出深度，累加 `weight×depth`。
两种方式结果必须一致，代码里互为校验。

### 3. 生成哈夫曼编码
- 叶→根回溯：对每个叶子 i，沿 parent 走到根，每一步判断"我是父结点的左孩子还是右孩子"，
  左记 '0' 右记 '1'，最后 **reverse**（因为是从后往前收集的）；
- 根→叶 DFS：路径上左走记 '0' 右走记 '1'，到叶子即得该字符编码。

### 4. 编码与解码
- 编码：查"字符 → 编码"表逐字符拼接；
- 解码：从根出发读比特流，'0' 走左、'1' 走右，**到达叶子就输出该字符并回到根**。
  前缀码保证任意时刻到达叶子即是一个完整字符，不存在歧义。

### 5. 树/森林 → 二叉树（孩子兄弟法）
规则一句话：**"左孩子、右兄弟"**——结点的第一个孩子变成二叉树中的左孩子，
相邻兄弟变成右孩子；森林中各棵树的根互为兄弟，所以**根的右链上依次挂着第 2、3…棵树的根**。
具体步骤：①各树内部按孩子兄弟法改写；②把 T1 根的 nextSibling 指向 T2 根，T2 → T3 …… 结果二叉树
的根就是 T1 的根。

### 6. 二叉树 → 森林（逆变换）
从根出发沿**右链**切开：右链上的每个结点各自成为一棵树的根；对每棵"斜树"再按
"左链是孩子、右链是兄弟"还原出普通树。代码中实现了这个还原并与原森林打印对比，验证往返一致。

## ⑤ 复杂度小结

| 操作 | 时间 | 空间 | 说明 |
| --- | --- | --- | --- |
| 构建哈夫曼树（线性扫描选最小两个） | O(n²) | O(n)（2n−1 结点数组） | 教材写法，n 小够用 |
| 构建哈夫曼树（优先队列） | O(n log n) | O(n) | 每次取两个最小 + 插入和值 |
| 生成全部编码（叶→根回溯） | O(n·h)，h 为树高 | O(n·h) 存编码 | 每个叶子走一条根路径 |
| 生成全部编码（根→叶 DFS） | O(n) | O(h) 递归栈 | 编码边走边拼 |
| 编码长度 L 的文本 | O(L) | O(L) | 查表拼接 |
| 解码长度 L 的比特串 | O(L) | O(1) | 每读 1 比特走 1 步 |
| 树/森林 ↔ 二叉树转换 | O(结点数) | O(1) 额外 | 只改指针 |

## ⑥ 常见易错点

1. **选最小两个时忘了跳过 parent≠0 的结点**——已被合并的结点不能再参加选择，否则树建错。
2. **数组开小了**：n 个叶子要开 `2n−1` 个结点（0 号弃用则开 2n），开成 n 是新手第一大致命错。
3. **叶→根回溯得到的编码是反的**：从父结点往回收集比特，必须 `reverse` 之后再存。
4. **左 0 右 1 只是约定**：约定反了 WPL 不变、码表不同；**编码和解码必须用同一棵树同一约定**。
5. **权值并列时树形不唯一**：不要以为自己的码表和别人的不一样就是错了，先比 WPL 是否相同。
6. **解码到一半比特流结束**：若最后停在半路（非叶子），说明串不合法——检查串长度是否完整。
7. **树转二叉树时把"右指针"当成"右孩子"**：右指针是兄弟；一根右链走到底是兄弟链，不是右子树。
8. **森林转二叉树忘了把各树根用右链串起来**：只转了每棵树、没连根，得到的是几棵散的树。
9. **WPL 只算叶子**：把内部结点的权也算进去（例如合并出来的和值），WPL 会算大。
10. **哈夫曼树不唯一 ≠ 算法错**：WPL 值唯一才是判定标准。
