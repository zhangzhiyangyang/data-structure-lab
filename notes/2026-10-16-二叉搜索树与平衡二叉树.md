# 二叉搜索树与平衡二叉树

> 学习笔记 · 2026-10-16 · 配套代码：[`code/2026-10-16-bst_avl.cpp`](../code/2026-10-16-bst_avl.cpp)

## 一、基本概念与术语

**二叉搜索树（Binary Search Tree, BST）** 又称二叉排序树、二叉查找树，它或者是一棵空树，或者满足：

1. 若左子树不空，则**左子树上所有**结点的值均**小于**根结点的值；
2. 若右子树不空，则**右子树上所有**结点的值均**大于**根结点的值；
3. 左、右子树本身也分别是一棵二叉搜索树。

第 1、2 条说的是「所有结点」而不是「左/右孩子」，这是 BST 与普通二叉树最容易被写错的分界点。

**平衡二叉树（AVL 树）** 是 Adelson-Velsky 与 Landis 提出的自平衡 BST：它首先是一棵 BST，并且**任一结点左右子树的高度差（平衡因子）的绝对值不超过 1**。

| 术语 | 含义 |
| --- | --- |
| 二叉搜索树 | 满足中序序列严格升序的二叉树 |
| 平衡因子 BF | `BF(p) = 高度(左子树) − 高度(右子树)` |
| 平衡二叉树 | 所有结点都有 `\|BF\| ≤ 1` 的二叉树 |
| 最小不平衡子树 | 插入/删除后，从修改点到根的方向上**离修改点最近**的 `\|BF\| > 1` 的子树 |
| LL 型 | 在左孩子的左子树插入导致失衡，需一次**右旋** |
| RR 型 | 在右孩子的右子树插入导致失衡，需一次**左旋** |
| LR 型 | 在左孩子的右子树插入导致失衡，需**先左旋后右旋** |
| RL 型 | 在右孩子的左子树插入导致失衡，需**先右旋后左旋** |
| ASL | 平均查找长度，衡量查找效率的核心指标 |
| 退化 | BST 的插入序列有序时，树退化成单支链表 |

## 二、核心性质与定理

### 1. BST 的中序遍历是升序序列

这是 BST 的定义性特征，也是最常用的性质：对 BST 做中序遍历（LDR），得到的序列严格升序（元素唯一时）。反过来，**一个序列升序 ⟺ 该二叉树按 BST 规则成立**（元素唯一时）。因此判断一棵二叉树是不是 BST，最直接的两种做法是「中序序列是否升序」或「递归传入上下界」。

注意：只比较「结点与其左右孩子」是**不够**的。反例：根 10，左孩子 20（比根大，但若再给 20 配一个值 15 的右孩子，局部检查会全部通过）。

### 2. n 个结点的 BST，树高决定查找效率

| 形态 | 树高 h | 查找/插入/删除平均时间 |
| --- | --- | --- |
| 完全平衡（理想） | `⌈log₂(n+1)⌉` | `O(log n)` |
| 随机插入 | `O(log n)` | `O(log n)` |
| 插入序列有序（最坏） | `n` | 退化为 `O(n)` |

**为什么会退化**：依次插入 `1, 2, 3, …, n` 时，每次新结点都落在当前最右结点的右孩子上，树退化成一条只有右孩子的链，此时查找等同于单链表的顺序查找。这正是引入 AVL 树的动机。

### 3. AVL 的高度上界

设 `N(h)` 表示高度为 `h` 的 AVL 树最少结点数。要让高度为 h 且结点数最少，根的两棵子树必然是高度分别为 `h−1` 和 `h−2` 的**最少结点** AVL 树，于是递推：

```
N(0) = 0,  N(1) = 1,  N(2) = 2
N(h) = N(h-1) + N(h-2) + 1        (h ≥ 3)
```

这个递推与斐波那契数列同阶，可解出 `N(h) ≈ (φ^h)/√5 − 1`（`φ = (1+√5)/2 ≈ 1.618`）。反解得：

```
h ≤ 1.44 · log₂(n + 2) − 0.328
```

结论：**n 个结点的 AVL 树高度是 `O(log n)`，且常数因子不超过 1.44**。这就是 AVL 树查找效率稳定为 `O(log n)` 的理论依据——**无论插入顺序如何**，AVL 都不会退化。

### 4. 旋转不改变中序序列

左旋与右旋都只是改变了结点之间的父子关系，**没有改变结点在水平方向上的相对次序**，所以旋转前后的中序序列完全一致，BST 性质得以保持。这是旋转操作合法性的一句话证明。

### 5. 插入最多只需一轮旋转，删除可能要 O(log n) 轮

- **插入**：新结点加入后，只有**从新结点到根**这条路径上的结点高度会变化。一旦在最低的不平衡结点处做完旋转，该子树高度恢复到插入前的值，其上所有祖先的 BF 自动恢复，无需继续调整。
- **删除**：删除会使子树高度**真的降低**，修复最低不平衡子树后，其高度可能比删除前更矮，导致祖先也可能失衡，因此必须**沿路径一直向上检查到根**，最多进行 `O(log n)` 次旋转。

## 三、存储结构

### 链式存储（推荐）

BST 与 AVL 都用链式存储，因为结点关系不规则，顺序存储会浪费大量空间：

```cpp
// 二叉搜索树结点
typedef struct BSTNode {
    int data;              // 数据域
    BSTNode *left, *right; // 左右孩子指针
} BSTNode, *BSTree;

// AVL 结点：多一个 height 域，用空间换 O(1) 的平衡因子查询
typedef struct AVLNode {
    int key;               // 关键字
    int height;            // 以本结点为根的子树高度（叶子为 1，空树为 0）
    AVLNode *left, *right;
} AVLNode, *AVLTree;
```

### 顺序存储

用数组存二叉树的规则是：下标 i 的左孩子为 `2i`、右孩子为 `2i+1`、双亲为 `⌊i/2⌋`（下标从 1 开始）。

| 对比项 | 顺序存储 | 链式存储 |
| --- | --- | --- |
| 结构要求 | 仅适合完全二叉树；非完全树需补空结点 | 任意二叉树 |
| 空间开销 | 最好 `n`，最坏可达 `2^h`（退化成链时为 `2^n`） | 固定 `n` 个结点，每结点 2 个指针 |
| 找孩子/双亲 | 下标直接计算，`O(1)` | 找孩子 `O(1)`，找双亲需额外 parent 指针或遍历 |
| BST 适用性 | 因形态无常，几乎不可用 | 标准选择 |

对 BST/AVL 而言，**链式存储是唯一实用选择**：树的形态由插入序列动态决定，无法预知，顺序存储的浪费不可接受。

## 四、核心操作的实现思路

### 1. BST 的插入

从根开始比较，小则向左、大则向右，走到空位置挂上新结点。递归写法最简洁：

```cpp
BSTNode* insert(BSTNode* t, int v) {
    if (!t) return new BSTNode(v);          // 走到空位，插入
    if (v < t->data)      t->left  = insert(t->left,  v);
    else if (v > t->data) t->right = insert(t->right, v);
    // v == t->data：已存在则不做任何事，保证元素唯一
    return t;
}
```

### 2. BST 的查找

可以用循环消除递归。每比较一次就砍掉一棵子树，效率完全取决于树高：

```cpp
bool search(const BSTNode* t, int v) {
    while (t) {
        if (v == t->data) return true;
        t = (v < t->data) ? t->left : t->right;
    }
    return false;
}
```

### 3. BST 的删除（三种情况）

删除是 BST 最容易写错的操作，必须分情况处理：

| 情况 | 被删结点的孩子 | 处理方式 |
| --- | --- | --- |
| 1 | 叶子结点 | 直接摘除，双亲对应指针置空 |
| 2 | 只有左孩子或只有右孩子 | 用唯一的那个孩子**顶替**自己的位置 |
| 3 | 左右孩子都不空 | 用**中序后继**（右子树最小结点）或中序前驱（左子树最大结点）的值覆盖自己，然后递归删除那个后继结点 |

情况 3 为什么选「右子树最小结点」：它是右子树中最小的，比左子树所有结点都大；又是右子树中最靠左的，删掉它不会破坏右子树的结构。用前驱也是对称可行的。

```cpp
BSTNode* remove(BSTNode* t, int v) {
    if (!t) return nullptr;
    if (v < t->data)      t->left  = remove(t->left,  v);
    else if (v > t->data) t->right = remove(t->right, v);
    else {
        if (!t->left || !t->right) {            // 情况 1、2
            BSTNode* child = t->left ? t->left : t->right;
            delete t;
            return child;                        // child 可能为 nullptr
        }
        BSTNode* s = minNode(t->right);          // 情况 3：中序后继
        t->data  = s->data;
        t->right = remove(t->right, s->data);
    }
    return t;
}
```

### 4. AVL 的四种旋转

旋转的目标是「把偏高的那一侧提上来」，同时保持中序序列不变。

先约定：右旋以 y 为轴（`y` 的左孩子 `x` 上升）：

```
旋转前：y 为根，左孩子 x；x 的左右孩子为 T1、T2；y 的右孩子为 T3
旋转后：x 成为根；x 的左孩子仍为 T1，x 的右孩子改为 y
        y 的左孩子改为 T2，y 的右孩子仍为 T3
```

左旋是右旋的镜像（`x` 的右孩子 `y` 上升）。四种失衡型的处理：

| 型 | 触发条件 | 操作 |
| --- | --- | --- |
| LL | `BF(t) > 1` 且 `BF(t->left) ≥ 0` | 对 t 右旋一次 |
| RR | `BF(t) < -1` 且 `BF(t->right) ≤ 0` | 对 t 左旋一次 |
| LR | `BF(t) > 1` 且 `BF(t->left) < 0` | 先对 `t->left` 左旋，再对 t 右旋 |
| RL | `BF(t) < -1` 且 `BF(t->right) > 0` | 先对 `t->right` 右旋，再对 t 左旋 |

**记忆口诀**：失衡方向看 BF 的符号，孩子 BF 的符号与父相反就是双旋（LR/RL），一致就是单旋（LL/RR）。双旋的动作顺序与型的名字相反——LR 要先左旋、RL 要先右旋。

```cpp
AVLNode* rotateRight(AVLNode* y) {
    AVLNode* x  = y->left;
    AVLNode* t2 = x->right;
    x->right = y;
    y->left  = t2;
    update(y);          // 先更新沉下去的 y
    update(x);          // 再更新升上来的 x
    return x;
}
```

**更新高度的顺序不能反**：`x->height` 依赖 `y->height`，必须先算 y。

再平衡的统一入口：

```cpp
AVLNode* rebalance(AVLNode* t) {
    update(t);                                    // 先刷新自身高度
    int balance = bf(t);
    if (balance > 1) {
        if (bf(t->left) < 0) t->left = rotateLeft(t->left);   // LR
        return rotateRight(t);
    }
    if (balance < -1) {
        if (bf(t->right) > 0) t->right = rotateRight(t->right); // RL
        return rotateLeft(t);
    }
    return t;
}
```

在插入/删除的递归回溯路上调用 `rebalance`，就自动完成了「从最低不平衡子树开始修复」的全过程。AVL 的插入与 BST 插入的唯一区别就是多这一行调用。

### 5. 求树高、结点数、叶子数

三者都是后序遍历框架的变体，先算左右子树再合并：

```cpp
int height(const BSTNode* t) {
    if (!t) return 0;
    return max(height(t->left), height(t->right)) + 1;
}
```

## 五、复杂度小结

BST（n 个结点，h 为树高，最坏 h = n）：

| 操作 | 平均时间 | 最坏时间 | 空间 |
| --- | --- | --- | --- |
| 查找 | O(log n) | O(n) | O(1) 迭代 / O(h) 递归 |
| 插入 | O(log n) | O(n) | O(h) |
| 删除 | O(log n) | O(n) | O(h) |
| 求最小值 / 最大值 | O(log n) | O(n) | O(1) |
| 中序遍历（输出有序） | O(n) | O(n) | O(h) |
| 建树（依次插入 n 个） | O(n log n) | O(n²) | O(n) |

AVL（n 个结点，恒有 h = O(log n)）：

| 操作 | 时间 | 说明 |
| --- | --- | --- |
| 查找 | O(log n) | 严格成立，无最坏退化 |
| 插入 | O(log n) | 常数因子略大于 BST，最多 1 次旋转 |
| 删除 | O(log n) | 最坏需 O(log n) 次旋转 |
| 旋转（左旋/右旋） | O(1) | 只改动常数个指针 |
| 辅助空间 | O(1) | 每结点额外一个 int 的 height 域 |

**取舍**：AVL 用「插入删除时多做几次旋转」换取「查找严格 O(log n)」。若插入删除远多于查找，红黑树（近似平衡，常数更小）通常更实用；若查找是主要操作，AVL 更优。

## 六、常见易错点

1. **判 BST 时只比较父子结点**。必须用「中序序列升序」或「递归传上下界」。局部比较会漏掉「孙子比爷爷大」这类非法结构。
2. **上下界用 int 导致溢出**。若结点值可能取到 `INT_MIN`/`INT_MAX`，界值要用 `long long` 的 `LLONG_MIN`/`LLONG_MAX`；若用 `int` 初始化成 `INT_MIN - 1` 会直接溢出。
3. **删除两个孩子结点时，忘记递归删除后继**。只覆盖值不删原后继，会在树中留下一个重复结点。
4. **删除情况 2 时判空顺序写错**。`if (!t->left) return t->right; if (!t->right) return t->left;` 这类写法中，两个孩子都为空时会先命中第一条，返回 `nullptr`，结果正确但依赖顺序；更稳妥的是显式写成一个孩子为空的判断再统一处理。
5. **AVL 旋转后更新高度的顺序颠倒**。先 `update(x)` 再 `update(y)`，会让 y 用到过期的子树高度，导致 height 域逐渐错误、后续判断失衡。
6. **双旋写成两次单旋的同向操作**。LR 必须「先左旋孩子、再右旋自己」，方向不能同向，否则越旋越歪。
7. **忘记在插入/删除回溯时调用 rebalance**。只在根处检查一次是不够的，失衡点可能在路径上任意一层。
8. **认为所有 BST 都是平衡的**。BST 只保证有序，不保证矮；插入有序序列必退化。需要稳定性能就得用 AVL / 红黑树。
9. **AVL 删除后只修一次失衡就不管了**。删除导致子树变矮，祖先可能连锁失衡，必须一路修到根。
10. **递归建树时没处理重复关键字**。BST 通常要求元素唯一，重复时是「丢弃」还是「计数器 +1」要事先定义清楚。

1. 写一个函数判断给定二叉树是否为二叉搜索树，要求不使用额外数组（不允许先做中序遍历存下来再检查），并说明为什么只比较父子结点是不够的。
